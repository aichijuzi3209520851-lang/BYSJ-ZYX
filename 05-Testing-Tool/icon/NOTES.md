## 1. v6 视觉母题「全息链路」

**深空底板 + 霓虹六边形 + 白色脉冲链路线。**

- **六边形**：十六进制字节 / IoT 节点 / 协议帧的通用符号，青→蓝→紫横向渐变霓虹描边；
- **白色脉冲线**：链路上的信号——大尺寸（≥48px）为「低 → 升 → 回落 → 高」四点链路波形，
  小尺寸（≤32px）简化为「低 → 升 → 高」三段（16px 下四点会挤成团）；
- **深空底板**：`#2A2063 → #0A0722` 纵向三段渐变（≤32px 用更亮窄域 `#332774 → #100B2E`）；
- **双层辉光**：外层宽模糊紫光（`#7A4FFF`，blur 2%n，gain 0.85）+
  内层窄模糊青光（`#00D0FF`，blur 1.4%n，gain 0.80），只给 ≥32px（更小只会变泥）。

与 EMQX（青蓝对角渐变+波纹飞机）在色相（深紫底 vs 亮青底）、构图（六边形 vs 自由曲线）、
光效（霓虹辉光 vs 平面渐变）三个维度全部拉开，见 `compare-emqx.png`。

### v6 关键参数（generate_icon.py 常量）

- `R_HEX`（六边形外接圆半径）：16px 必须外扩到 0.400（0.36 会塌成「O」环），
  256px 收到 0.330；`STROKE_HEX`：16px 0.150 → 256px 0.052。
- `PULSE_FULL`（≥48px 四点）：256px `[(0.260,0.680),(0.455,0.680),(0.585,0.275),(0.760,0.430)]`；
  `PULSE_SMALL`（≤32px 三点）：16px `[(0.245,0.640),(0.545,0.640),(0.745,0.340)]`——
  横段要长、上升要陡，否则 16px 读成「对勾」（v6 实测后修正）。
- `STROKE_PULSE`：16px 0.110 → 256px 0.044。

### v6 两轮探索记录（过程脚本已删，结论留档）

第一轮三候选：A 霓虹脉冲（心电波形）——256px 炫但 16px 塌成对称「十」字（误读为医疗十字）；
B 雷达扫描——语义与 MQTT 调试关联弱、16px 发糊；C 全息六边形链路——胜出。
第二轮 C 精修：C1 六辐条节点版——16px 辐条糊成雪花环，弃；C2 内辉光版——同弃；
C3 六边形+脉冲线版——定稿。

## 2. v6 迭代史（v1 → v6）

- **v1 双向箭头**：被用户否决（通用「排序/交换」字形）。
- **v2/v3 浅底绿波形**：白底资源管理器里视觉重量远低于 EMQX，证伪。
- **v4 单边信号沿（竖向渐变平铺）**：字形正确，观感扁平。
- **v5 径向辉光绿版**：径向辉光+rim+投影，观感升级，但用户仍要求**完全换样式、要炫酷**——
  绿底方块路线整体推翻。
- **v6（本版）**：深空紫底霓虹六边形+脉冲链路线，与 v4/v5 完全不同的样式方向。

## 3. 渲染层次（v6）

1. 深空底板：逐行渐变（1px 列拉伸，NEAREST，无中间缩放伪影）+ 圆角矩形 mask；
2. 紫色外辉光：六边形 mask 高斯模糊后叠加（≥32px）；
3. 青色脉冲辉光：脉冲线 mask 高斯模糊后叠加（≥32px）；
4. 霓虹六边形：横向三段渐变描边（≤32px 用更亮 GRAD_HEX_BRIGHT）；
5. 白色脉冲线：`#F6FDFF` 近纯白；
6. alpha 地板：`_ALPHA_FLOOR = 6` 清理圆角外残留。

技术管线与 v4/v5 相同：8x 超采样 + LANCZOS、手写 ICO 容器
（16–64px 32bpp DIB + 1bpp AND mask，128/256 PNG frame）。

## 5. 自检与部署链路

```bash
python generate_icon.py   # 生成 app.ico + 全部 preview
python verify_icon.py     # PASS 101 / FAIL 0
python make_compare.py    # 重生成 EMQX 对比图
```

部署链路（v6 已执行）：
1. `icon/app.ico` → 复制到 `WinFormsApp1/app.ico`
2. 关闭运行中的 `IotLinkLab.exe` → 删除 `bin/`、`obj/` → `dotnet build -c Release`（0 警告 0 错误）
3. exe 内嵌校验：256×256 PNG frame 存在；ExtractAssociatedIcon 提取自证为 v6 渲染
   （`exe-icon-extract.png`）
4. `ie4uinit.exe -show` + `SHChangeNotify(SHCNE_ASSOCCHANGED)` 刷新图标缓存与桌面
5. 桌面快捷方式 `IotLinkLab 物联网链路调试台.lnk` 指向 Release exe（v5 时已建，沿用）

**注意**：`03-EMQX-Server/app.ico`（sha256 `c6367851930dc0b8…`）保持不动。

## 6. 被证伪方向总表（v1–v6 全部，记录以免重犯）

| 方向 | 失败原因 |
|---|---|
| 竖向双箭头（v1） | 通用「排序/交换」字形，不表达串口/MQTT |
| 浅底 + 绿色波形（v2/v3） | 白底资源管理器里视觉重量远低于 EMQX，16px 像空图标 |
| 对称双足脉冲 | 必被读成 `Π` / 桌子 / 订书钉 |
| 多脉冲 / 双脉冲波形 | 16px 时凹槽归零，填实成色块 |
| 青/靛双色描边编码方向 | 看起来像「条纹旗杆」，不是波形 |
| 实心多边形填充 | 16px 塌成柱状图 / 像素点 |
| 双节点 + 连接线 | 16px 含糊；「圆 + 块」被读成人像 avatar |
| `>_` 终端提示符 | 清晰但属通用开发者符号，产品特异性不足 |
| 芯片 + 引脚 | 只是「通用 IoT 硬件」，不够精确 |
| 末端发光圆点（v5 探索） | ≤32px 圆点变噪点 |
| 半透明示波屏（v5 探索） | 渲染管线里塌成白色实心块 |
| 512px canvas 再缩 16px（v5 探索） | 径向渐变块状色带伪影 → 渐变必须逐像素按目标分辨率计算 |
| 绿底信号沿整套（v4/v5） | 用户要求完全换样式：绿色系整体推翻 |
| 心电波形霓虹版（v6-A） | 16px 塌成对称「十」字，误读为医疗十字 |
| 雷达扫描（v6-B) | 与 MQTT 调试语义关联弱；16px 发糊 |
| 六边形+六辐条节点（v6-C1/C2） | 16px 辐条糊成雪花环 |
| v6 六边形 16px 用 R=0.36 | 塌成「O」环 → 16px 必须 R=0.400 |
| v6 脉冲线首版 16px 几何 | 读成「对勾」→ 横段加长 (0.245→0.545)、上升段加陡 |

## 7. 历史归档：v5 径向辉光版设计说明（已被 v6 取代，留档备查）

v5 母题为绿底「单边信号沿」（低电平→上升沿→高电平），五层渲染：
径向辉光底板（光心 30%,24%，`#3BCB72→#178A44→#0A4A24`，≤32px 亮窄域）→
玻璃 rim light（1% 内描边，顶部 α110/底 α24，<48px 减半）→ 字形投影（≥32px，
α0.24@≥64/α0.16@32-48，<32px 关）→ 白色信号沿 → alpha 地板。
品牌色锚点 `WinFormsApp1/Theme.cs`（`#15803D`/`#0E592C`）。
v5 当时实测教训：16px 小尺寸必须加粗线条、底板近满版（LANCZOS 缩小后不糊的核心）。
