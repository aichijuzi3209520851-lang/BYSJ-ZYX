# 真机调试MQTT连接指南

## 问题描述
微信开发者工具可以连接MQTT服务器，但手机真机调试无法连接。

## 根本原因
手机真机调试时，手机必须能够通过网络访问到电脑上的MQTT服务器。这需要满足特定的网络条件。

---

## ⚠ 最常见的坑：填了虚拟网卡地址（2026-11-02 实测确认）

**症状**：开发者工具模拟器里秒连、状态栏变绿、数据正常刷新；一上手机就转圈直到超时。控制台日志里能看到 `ws://192.168.40.1:8083/mqtt` 这样的地址。

**原因**：`192.168.40.1` 是 **VMware 的虚拟网卡（VMnet8）**，不是电脑的局域网地址。它只存在于这台电脑内部 —— 模拟器恰好也跑在这台电脑上，所以连得通；手机是另一台设备，它所在的热点网段里根本没有这个地址。

这就是"模拟器能连、真机连不上"最常见的真相：**不是服务器问题、不是防火墙问题、也不是代码问题，是地址填错了。**

### 本机实测的网卡对照（可作为自查范例）

| 网卡 | 类型 | IPv4 | 默认网关 | 手机能用吗 |
| --- | --- | --- | --- | --- |
| WLAN（MediaTek Wi-Fi 6 MT7921） | 物理无线网卡 | `192.168.46.46` | `192.168.46.240` | ✅ **只能填这个** |
| VMware Network Adapter VMnet1 | 虚拟 | `192.168.198.1` | 空 | ❌ |
| VMware Network Adapter VMnet8 | 虚拟 | `192.168.40.1` | 空 | ❌ |
| vEthernet (Default Switch) | Hyper-V 虚拟 | `172.20.144.1` | 空 | ❌ |
| Tailscale | 组网工具隧道 | `100.86.134.42` | 空 | ❌ |

### 一秒判断法：看有没有默认网关

```cmd
ipconfig
```

**有"默认网关"这一项且非空的，才是你真正连在路由器/热点上的那张网卡。** 虚拟网卡的网关恒为空。

也可以直接用 PowerShell 列出来（`Gateway` 为空的是虚拟网卡）：

```powershell
Get-NetIPConfiguration | Select-Object InterfaceAlias, @{n='IPv4';e={$_.IPv4Address.IPAddress}}, @{n='Gateway';e={$_.IPv4DefaultGateway.NextHop}}
```

或者直接看 EMQX 启动器打印的地址列表 —— 它现在会标出 `★ WLAN —— 手机就用这个`，并把虚拟网卡标注为"虚拟网卡, 手机连不上, 勿用"。

### 记住这几条铁律

| 地址 | 手机真机 | 说明 |
| --- | --- | --- |
| `127.0.0.1` / `localhost` | ❌ | 手机会连到手机自己 |
| `192.168.x.1`（末位是 1） | ⚠ 多半是虚拟网卡 | VMware / Hyper-V 宿主机侧地址常见此形态，务必核对 |
| `172.16.x.x` ~ `172.31.x.x` | ❌ 多半是虚拟网卡 | Hyper-V / WSL2 常用段 |
| `100.64.x.x` ~ `100.127.x.x` | ❌ | Tailscale / CGNAT 段，手机没装客户端连不上 |
| 有默认网关那张网卡的 `192.168.x.x` | ✅ | 这才是要填的 |

> 小程序侧会做校验：填到上述可疑地址时会弹「这个地址手机连不上」并说明原因；配置弹窗里也会边输入边提示。该提示**只提醒不拦截** —— 如果你确实把 EMQX 装在某个虚拟网段上（例如 VPN 组网），可以继续连接。

## 解决步骤

### 第1步：确保手机和电脑在同一局域网 ⭐⭐⭐

**这是最关键的一步！**

1. **手机连接WiFi**
   - 打开手机的WiFi设置
   - 连接到与电脑**相同的WiFi网络**
   - 记录连接的WiFi名称

2. **检查电脑网络**
   - 确保电脑也连接到同一个WiFi网络
   - **不要使用有线网络和无线网络混合**（如果电脑同时连接了有线和WiFi，请断开一个）

3. **验证方式**
   ```
   手机WiFi名称 = 电脑WiFi名称
   ```

### 第2步：获取并验证电脑IP地址

#### 2.1 获取电脑的局域网IP地址

**Windows系统：**

打开命令提示符（Win+R，输入cmd），执行：
```cmd
ipconfig
```

查找 **"无线局域网适配器 WLAN"** 部分：
```
无线局域网适配器 WLAN:
   IPv4 地址 . . . . . . . . : 192.168.1.100  ← 这就是你需要的IP
```

**重要提示：**
- ✓ 使用 `192.168.x.x` 格式的IP地址
- ✓ 使用 `10.x.x.x` 格式的IP地址
- ✗ 不要使用 `127.0.0.1`（这是本机回环地址）
- ✗ 不要使用 `localhost`
- ✗ **不要使用任何虚拟网卡的地址**（VMware / Hyper-V / Tailscale / WSL）—— 详见开头「最常见的坑：填了虚拟网卡地址」一节。`ipconfig` 里**看「默认网关」非空的那一块**，那才是手机能连的地址。

#### 2.2 验证手机能否访问电脑IP

**方法一：使用手机浏览器测试**

在手机浏览器中访问：
```
http://你的电脑IP:18083
```
例如：`http://192.168.1.100:18083`

如果能打开EMQX Dashboard登录页面，说明网络连通。

**方法二：使用手机端网络工具**

下载"Network Analyzer"等网络工具App，ping电脑的IP地址。

### 第3步：配置EMQX允许外部访问

#### 3.1 检查EMQX绑定地址

编辑 `emqx.conf` 配置文件，确保WebSocket监听器绑定到 `0.0.0.0` 而不是 `127.0.0.1`：

```conf
listeners.ws.default {
  bind = "0.0.0.0:8083"     # 监听所有网络接口
  websocket.mqtt_path = "/mqtt"
}
```

#### 3.2 重启EMQX服务

```cmd
emqx stop
emqx start
```

### 第4步：检查Windows防火墙

即使你说防火墙没开启，也请确认一下：

#### 4.1 关闭防火墙（临时测试）

1. 打开"Windows Defender 防火墙"
2. 点击"启用或关闭Windows Defender 防火墙"
3. 将"专用网络"和"公用网络"都设为关闭
4. 测试连接

#### 4.2 如果关闭防火墙后能连接，则添加规则

打开PowerShell（管理员权限）：
```powershell
# 添加入站规则
New-NetFirewallRule -DisplayName "EMQX WebSocket" -Direction Inbound -Protocol TCP -LocalPort 8083 -Action Allow

# 添加出站规则
New-NetFirewallRule -DisplayName "EMQX WebSocket Out" -Direction Outbound -Protocol TCP -LocalPort 8083 -Action Allow
```

### 第5步：在小程序中更新IP地址

1. **在微信开发者工具中运行小程序**
2. **进入"传感器"页面**
3. **点击右上角的设置图标**
4. **修改MQTT服务器地址为电脑的实际IP**（从第2步获取）
   ```
   服务器地址: 192.168.1.100（改成你的实际IP）
   端口: 8083
   主题: LCW2
   ```
5. **点击"保存并连接"**

### 第6步：启用真机调试

#### 6.1 在微信开发者工具中

1. 点击顶部工具栏的"预览"按钮旁边的"真机调试"按钮
2. 选择"真机调试"
3. 扫描生成的二维码

#### 6.2 在手机上

1. 使用微信扫描二维码
2. **重要：首次会提示"打开调试"，必须点击确认**
3. 小程序会以调试模式启动
4. 可以看到右下角有一个绿色的"vConsole"按钮

#### 6.3 开启调试日志

- 点击手机屏幕右下角的绿色"vConsole"按钮
- 切换到"Log"标签页
- 现在可以看到详细的连接日志

### 第7步：检查连接日志

在vConsole中查看日志，应该看到：

**成功时的日志：**
```
===== MQTT连接开始 =====
连接URL: ws://192.168.1.100:8083/mqtt
✓ WebSocket连接请求已发送
✓ WebSocket连接已成功建立
✓ MQTT CONNECT包发送成功
✓ 收到CONNACK确认包
✓ 收到SUBACK确认包，订阅成功
```

**失败时的典型错误：**
```
✗ WebSocket连接请求失败
errMsg: "connectSocket:fail (系统暂忙，请稍后再试)"
```

## 常见问题及解决方案

### 问题1：一直显示"正在连接..."然后超时

**原因：** 手机无法访问到电脑的IP地址

**先排除这一条（命中率最高）：地址填的是虚拟网卡。**
如果模拟器能连、手机不能连，先去 `ipconfig` 看那张网卡的"默认网关"是不是空的 ——
空的就不是真正连在热点上的网卡。详见开头「最常见的坑：填了虚拟网卡地址」。

**其它可能：**
1. 确认手机和电脑连接同一WiFi
2. 尝试关闭电脑防火墙测试
3. 检查路由器是否开启了"AP隔离"功能（需要在路由器设置中关闭）

### 问题2：提示"不在以下合法域名列表中"

**原因：** 真机调试没有开启调试模式

**解决方案：**
1. 确保使用"真机调试"而不是"预览"
2. 首次扫码时必须点击"打开调试"
3. 在小程序右下角应该能看到绿色的vConsole按钮

### 问题3：IP地址经常变化

**原因：** 电脑使用DHCP自动获取IP，每次连接可能不同

**解决方案A - 使用静态IP（推荐）：**

1. 打开"控制面板" → "网络和共享中心"
2. 点击你的WiFi连接
3. 点击"属性"
4. 双击"Internet 协议版本 4 (TCP/IPv4)"
5. 选择"使用下面的IP地址"
6. 设置静态IP，例如：
   ```
   IP地址: 192.168.1.100
   子网掩码: 255.255.255.0
   默认网关: 192.168.1.1（你的路由器IP）
   首选DNS: 192.168.1.1
   ```

**解决方案B - 在路由器中绑定MAC地址：**
1. 登录路由器管理界面
2. 找到"DHCP服务器" → "静态地址分配"
3. 为电脑的MAC地址绑定固定IP

### 问题4：学校或公司WiFi无法连接

**原因：** 某些WiFi网络有AP隔离，禁止设备间互相访问

**解决方案：**
1. 使用手机开热点，让电脑连接手机热点
2. 电脑IP会变成 `192.168.43.x` 或类似格式
3. 在小程序中更新IP地址后重新连接

### 问题5：能连接但收不到数据

**原因：** MQTT服务器没有发布消息到订阅的主题

**测试方法：**
使用MQTTX客户端发布测试消息：
```
主题: LCW2
消息: {"temperature":25.5,"humidity":60,"waterLevel":30,"airQuality":"nice","warning":false}
```

## 网络拓扑图

### 正确的连接方式
```
[路由器/WiFi]
      |
      |--- [电脑] (192.168.1.100:8083) - EMQX服务器
      |
      |--- [手机] - 微信小程序
```

### 错误的连接方式
```
[路由器] --- [电脑] (有线连接)

[手机] --- (WiFi连接)
```
手机和电脑在不同网络段，无法互通。

## 快速诊断脚本

将以下内容保存为 `check_network.bat`，在电脑上运行：

```batch
@echo off
echo ==========================================
echo MQTT真机调试网络诊断
echo ==========================================
echo.

echo [1/3] 检查电脑IP地址
echo ------------------------------------------
ipconfig | findstr /C:"IPv4"
echo.

echo [2/3] 检查EMQX进程
echo ------------------------------------------
tasklist | findstr /C:"emqx"
if %errorlevel%==0 (
    echo EMQX服务正在运行
) else (
    echo 警告: EMQX服务未运行!
)
echo.

echo [3/3] 检查8083端口监听状态
echo ------------------------------------------
netstat -ano | findstr ":8083"
echo.

echo ==========================================
echo 诊断完成
echo ==========================================
echo.
echo 请将上面显示的IPv4地址填入小程序配置中
echo.
pause
```

## 终极解决方案：使用手机热点

如果以上所有方法都不行，使用这个方案100%可以工作：

1. **手机开启热点**
   - 进入手机设置 → 个人热点/网络共享
   - 开启"便携式热点"
   - 记住热点名称和密码

2. **电脑连接手机热点**
   - 在电脑上连接到手机的热点WiFi
   - 等待连接成功

3. **获取电脑新IP**
   ```cmd
   ipconfig
   ```
   找到 WLAN 适配器的IP（通常是 `192.168.43.x`）

4. **重启EMQX**
   ```cmd
   emqx stop
   emqx start
   ```

5. **更新小程序配置**
   - 在小程序中更新为新的IP地址
   - 连接测试

6. **关闭手机热点，使用真机调试**
   - 现在可以关闭热点
   - 手机和电脑通过热点建立的"连接记忆"可能还在
   - 或者保持热点开启进行开发

## 总结

真机调试MQTT连接的核心要点：
1. ✅ 手机和电脑必须在同一WiFi网络
2. ✅ 使用电脑的局域网IP（192.168.x.x）
3. ✅ EMQX绑定到0.0.0.0而不是127.0.0.1
4. ✅ 防火墙允许8083端口
5. ✅ 使用"真机调试"而不是"预览"
6. ✅ 首次必须开启调试模式

完成这些步骤后，真机调试应该可以正常连接MQTT服务器！
